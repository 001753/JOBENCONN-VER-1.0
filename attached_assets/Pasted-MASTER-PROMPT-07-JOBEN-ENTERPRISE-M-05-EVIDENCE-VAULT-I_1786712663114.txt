PHASE 8 — SHA-256
============================================================

Compute SHA-256 over the canonical bytes.

Store:

contentHash

Hash must be calculated:

1. before object write
2. as part of commit validation
3. during verification

Conceptually:

<tenant>/<evidence-type>/<sha256>

Do not expose raw internal storage credentials.

Do not allow arbitrary client-provided hash
to become trusted evidence hash.

Server calculates the authoritative hash.

PHASE 14 — INTEGRITY VERIFICATION
============================================================

2. verify object exists
3. retrieve canonical bytes
4. recompute SHA-256
5. compare with contentHash
6. verify metadata consistency
