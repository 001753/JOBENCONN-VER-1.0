==================================================
2. DESIGN PHILOSOPHY
==================================================

JOBEN is not a generic analytics dashboard.

JOBEN is a SECURITY DECISION SYSTEM.

The UI must communicate this hierarchy:

WHY
→ WHAT HAPPENED
→ WHAT IS AT RISK
→ WHAT IS THE EVIDENCE
→ WHAT SHOULD I DO
→ VERIFY

Every important dashboard object should eventually support drill-down.

Example:

Security posture
→ finding
→ control
→ affected AWS resource
→ observed fact
→ evidence
→ timestamp
→ provenance
→ remediation

Never design cards that are visually attractive but disconnected from the underlying evidence model.

==================================================

Use the supplied reference as visual inspiration.

Desired characteristics:

DARK MODE:
- near-black / charcoal background
- slightly lighter surface panels
- thin low-contrast borders

- dark charcoal text

- subtle borders
- no pure-white-on-white ambiguity
- no low-contrast gray text
- preserve the same hierarchy as dark mode

Dark and light modes must feel like THE SAME PRODUCT.

Do not design one mode as an afterthought.
