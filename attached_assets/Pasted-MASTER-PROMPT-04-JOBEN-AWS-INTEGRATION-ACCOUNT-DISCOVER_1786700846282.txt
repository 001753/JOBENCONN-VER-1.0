4. AWS CREDENTIAL ARCHITECTURE
============================================================

Credential handling adalah SECURITY-CRITICAL.

Jangan menyimpan AWS secret access key
sebagai plaintext di database.

Jangan menaruh credential di frontend.

Jangan mengirim secret melalui URL.

Jangan menulis credential ke log.

Jangan menyimpan credential di audit event.

Gunakan abstraction:

AwsCredentialProvider

atau equivalent existing architecture.

Provider harus dapat mendukung:

- temporary credentials
- role assumption
- external credential source
- future AWS Organizations integration

Jangan mengunci seluruh system
pada satu credential strategy.

30. RETRY POLICY
============================================================

Retry hanya untuk transient failures.

Retry candidates:

certain 5xx

DO NOT blindly retry:

Invalid credentials
Validation error
NotFound

Use bounded retry.

No infinite retries.
