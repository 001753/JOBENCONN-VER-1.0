11. SCAN NOW
============================================================

Implementasikan Scan Now.

Flow:

POST Scan Now
→ authenticate
→ authorize
→ validate integration
→ validate provider readiness
→ idempotency check
→ create/reuse ScanRun
→ enqueue
→ return accepted/run reference
→ worker executes
→ client polls status

jika architecture existing memang mendukung.

Untuk scan berat:

Jangan memblok HTTP request
selama full scan.

19. WORKER LOOP
============================================================

23. RETRY POLICY
============================================================

Retry HANYA untuk transient failure.

PRD:

429
500
503
transient provider failure

Gunakan exponential backoff.

Maximum:

3 retry attempts.

401 / 403:

JANGAN retry otomatis.

Catat sebagai execution/permission error.

============================================================
24. RETRY FORMULA
============================================================

Harus ada upper bound.

Jangan infinite retry.

Jangan busy loop.

Retry harus tercatat:

attempt
reason
next attempt time
last error.

deterministic provider test double.

→ Provider Contract
→ actual AWS adapter.

============================================================

yang sudah dibuat Prompt 05.

Jangan implementasikan ulang
credential verification.

Jangan hardcode AWS credential.

Pastikan orchestration dapat
memanggil verified AWS integration.

Jika AWS live credential belum tersedia:

JANGAN mengklaim live verified.

Tetap test contract
dengan safe test adapter.
