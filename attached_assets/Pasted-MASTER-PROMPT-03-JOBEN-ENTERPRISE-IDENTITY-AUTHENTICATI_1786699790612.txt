5. IDENTITY ARCHITECTURE
============================================================

Pisahkan:

AUTHENTICATION
dan
AUTHORIZATION.

"Siapa user ini?"

"Apa yang boleh dilakukan user ini

External identity provider ID
adalah reference,
BUKAN primary domain identity.

22. OWNER PROTECTION
============================================================

zero active owners.

Owner A cannot remove/demote Owner B
if B is the last remaining owner.

- remove last owner → DENY
- demote last owner → DENY
- deactivate last owner → DENY
- transfer ownership → valid only when replacement owner exists
